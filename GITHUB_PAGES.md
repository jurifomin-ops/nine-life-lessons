# Публикация сайта на GitHub Pages

Сайт «Девять фундаментальных уроков жизни» полностью статический и готов к бесплатной публикации через GitHub Pages. После каждого обновления в ветке `main` сайт пересобирается и публикуется автоматически.

**Адрес после публикации:**
`https://jurifomin-ops.github.io/nine-life-lessons/`

---

## Шаг 1 — Подключить Replit к GitHub

1. В левой боковой панели Replit нажмите на иконку **Git** (похожа на разветвлённую стрелку).
2. Нажмите кнопку **Connect to GitHub**.
3. Войдите в аккаунт GitHub и разрешите доступ Replit, если потребуется.

---

## Шаг 2 — Подключить репозиторий

1. В панели Git выберите **Existing repository** (существующий репозиторий).
2. Введите или выберите из списка: `jurifomin-ops/nine-life-lessons`.
3. Нажмите **Connect**.

---

## Шаг 3 — Отправить код в GitHub

1. В панели Git вы увидите список изменённых файлов.
2. В поле **Commit message** напишите любое описание, например: `Первая публикация сайта`.
3. Нажмите **Commit & Push**.
4. Все файлы проекта отправятся в репозиторий в ветку `main`.

---

## Шаг 4 — Включить GitHub Pages в репозитории

1. Откройте репозиторий на GitHub: `https://github.com/jurifomin-ops/nine-life-lessons`
2. Перейдите в **Settings** (Настройки) — вкладка в верхнем меню репозитория.
3. В левом меню найдите раздел **Pages**.
4. В блоке **Source** выберите **GitHub Actions** (не Branch).
5. Нажмите **Save**.

---

## Шаг 5 — Дождаться публикации

1. Перейдите во вкладку **Actions** репозитория.
2. Вы увидите запущенный процесс с названием **Публикация на GitHub Pages**.
3. Дождитесь зелёной галочки — обычно это занимает 2–4 минуты.
4. После этого сайт доступен по адресу:
   `https://jurifomin-ops.github.io/nine-life-lessons/`

---

## Как обновить сайт в будущем

Каждый раз, когда вы отправляете изменения из Replit в GitHub (Commit & Push), GitHub Actions автоматически пересобирает и публикует сайт. Вам ничего дополнительно делать не нужно.

## Часто задаваемые вопросы

**Вкладка Actions не появляется в репозитории.**
Убедитесь, что в репозитории есть файл `.github/workflows/deploy.yml`. Он создаётся автоматически при отправке кода из Replit.

**Actions запускается, но завершается с ошибкой.**
Проверьте, что в настройках Pages выбран источник **GitHub Actions**, а не Branch.

**Сайт открывается, но стили не загружаются.**
Убедитесь, что URL содержит `/nine-life-lessons/` в конце. Прямой адрес без подпапки работать не будет.
